# The Wolf Pack

`wolf_walk.png` is the black wolf's run cycle from [The Wolf Pack](https://finalbossblues.itch.io/wolf-pack) by finalbossblues (full colour version), re-packed to `PlayerView`'s layout: a column per facing (down, up, left, right), a row per frame, 32×32 frames.
