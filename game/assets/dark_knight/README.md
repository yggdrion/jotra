# Dark Fantasy knight

`knight_walk.png` is the run cycle of jfranciPX's [Free Knight Player Character](https://jfranci-px.itch.io/free-knight-character) (the demo of their Dark Fantasy asset pack), re-packed to `PlayerView`'s layout: a column per facing (down, up, left mirrored from right, right), a row per frame, 48×48 frames with the feet on the bottom edge. `knight_blue_walk.png` is the same with the red cape turned blue (the second player look).
