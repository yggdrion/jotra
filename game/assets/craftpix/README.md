# CraftPix freebies

Cut and packed from three free CraftPix packs (by Free Game Assets on itch.io):

- [Free Undead Pixel Tileset Top Down](https://free-game-assets.itch.io/free-undead-tileset-top-down-pixel-art): `tiles/` and `props/`
- [Free Orc Pixel Characters Sprites](https://free-game-assets.itch.io/free-top-down-orc-game-character-pixel-art): `characters/orc_walk.png`, `draugr_walk.png` (drained of colour), `barrow_lord_walk.png` (likewise)
- [Free Base Top-Down Female Character](https://free-game-assets.itch.io/free-base-4-direction-female-character-pixel-art): `characters/wanderer_walk.png`

Walk sheets are re-packed to `PlayerView`'s layout: a column per facing (down, up, left, right), a row per frame, 48×48 frames with the feet on the bottom edge.
